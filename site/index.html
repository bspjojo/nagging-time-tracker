Nagging Time Tracker

A Windows system-tray time tracker that nags you to keep your timesheet honest.

Download for Windows

Latest version · Windows 10 or 11, 64-bit · All releases and notes

What it does

  • Start, stop, continue and edit timers from the tray. Each entry has a customer, a task type, an optional link and notes.
  • Run several timers at once, but only on purpose: a second one asks first, and the tray icon shows how many are running.
  • Nags you when nothing is tracked during work hours, checks in while a timer runs, and shows your own scheduled reminders.
  • Notices when you've been away and asks what to do with the idle time.
  • Exports to CSV for timesheets and invoicing elsewhere.
  • Keeps everything on your PC: no account, no sync, no telemetry.

Installing

  • Install installs it just for you, with no admin rights.
  • Advanced lets you install it for all users of the PC instead (asks for admin rights).
The installer isn't code-signed yet, so Windows SmartScreen may say Windows protected your PC. Choose More info, then Run anyway.

Updating and uninstalling

  • To update, download and run the newer installer. It closes the running app first; running timers are kept.
  • Your data lives in %LOCALAPPDATA%\NaggingTimeTracker, with daily backups of the last 7 days. Uninstalling keeps it; delete that folder yourself to remove it.
  • Uninstall from Settings → Apps.
